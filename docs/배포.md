# 배포 (6단계)

쓰는 사람에게 건네는 길은 셋이다. **파이썬을 깔 수 없는 PC면 ③**, 개발·수정까지 하면 ①.

| 길 | 받는 것 | 쓰는 쪽에 필요한 것 |
| --- | --- | --- |
| ① 저장소에서 바로 | 소스 전부 | Python 3.11+ · git |
| ② 꾸러미 (`.whl`) | `pip install imgvec-0.1.0-py3-none-any.whl` | Python 3.11+ |
| ③ 실행 파일 (`imgvec-windows.zip`) | 풀고 `imgvec.exe` | 없음 (약 330 MB, 압축 ~110 MB) |

## ① 저장소에서

```powershell
git clone https://github.com/lake44/IMG2DNCAD.git
cd IMG2DNCAD
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev,pdf,ocr]"
.\.venv\Scripts\Activate.ps1
imgvec --version
```

고정본으로 똑같은 조합을 쓰려면 `python -m pip install -r requirements-lock.txt` 를 먼저 합니다.

## ② 꾸러미 만들기

```powershell
python -m pip install build
python -m build                      # → dist\imgvec-0.1.0-py3-none-any.whl, .tar.gz
python -m pip install dist\imgvec-0.1.0-py3-none-any.whl
```

꾸러미에는 DNCAD 백업 템플릿(`imgvec/data/dncad_template.json`)이 함께 들어갑니다. 샘플·문서·시험은 들어가지 않습니다.

접속점 **이름 읽기**는 선택입니다 — `pip install "imgvec[ocr]"` (rapidocr-onnxruntime, 약 90 MB).
깔지 않으면 이름 자리에 번호가 붙을 뿐 나머지는 그대로 돕니다.

## ③ 실행 파일 (파이썬 없는 PC용)

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm packaging\imgvec.spec
dist\imgvec\imgvec.exe --version
```

- **만든 PC의 운영체제용만 나옵니다.** 윈도우 실행 파일은 윈도우에서 만들어야 합니다 (GitHub Actions의 `windows-exe` 일이 대신 합니다).
- 폴더째 복사해 씁니다(`dist\imgvec\`). 한 파일(onefile)로 묶지 않은 까닭은 첫 실행이 느려지기 때문입니다.
- 크기가 큰 까닭은 numpy·scipy·OpenCV·scikit-image가 통째로 들어가서입니다 (리눅스 실측 332 MB).
- 콘솔 한글은 `packaging/entry.py`가 UTF-8로 맞춰 둡니다.

## 자동으로 도는 것 (GitHub Actions)

| 일 | 언제 | 하는 일 |
| --- | --- | --- |
| `.github/workflows/ci.yml` | 밀 때마다·PR | 윈도우·리눅스 × Python 3.11·3.13에서 린트와 시험. 그리고 **만든 꾸러미로 그림 한 장을 백업까지** 돌려 본다 |
| `.github/workflows/release.yml` | `v*` 태그 | 꾸러미 + 윈도우 실행 파일을 만들어 릴리스에 붙인다 |

```powershell
git tag v0.1.0
git push origin v0.1.0        # → 릴리스에 whl · tar.gz · imgvec-windows.zip
```

## 판 올리기

판 번호는 **두 곳**에 있고 같아야 합니다 — `pyproject.toml`의 `version`과 `src/imgvec/__init__.py`의 `__version__`.
(어긋나면 `tests/test_packaging.py`가 잡습니다.)

| 무엇이 바뀌면 | 올리는 자리 |
| --- | --- |
| 고친 것·작은 보탬 | 0.1.**1** |
| 명령·출력이 늘거나 바뀜 | 0.**2**.0 |
| 배치 명세·장치 모델 스키마가 바뀜 | **1**.0.0 과 `docs/장치-모델-스키마.md`의 버전 정책 |

## 건네기 전에 보는 것

```powershell
python -m ruff check src tests tools packaging
python -X utf8 -m pytest -q                       # 화면 시험은 화면이 없으면 스스로 건너뜁니다
imgvec selftest                                   # 1단계 정확도
imgvec device autotest samples\set                # 4단계 자동 인식 정확도
```

## 알아 둘 것

- `requirements-lock.txt`의 네 줄(networkx·numpy·scipy·tifffile)은 2026-10-08에 PyPI에서 받을 수 없는 판이어서
  받을 수 있는 판으로 내렸습니다. 다른 곳에서 더 높은 판을 쓰고 있었다면 그 환경의 값으로 되돌리세요.
- 실행 파일은 바이러스 검사 프로그램이 처음에 막는 일이 있습니다 (PyInstaller 공통). 사내 배포라면 서명을 붙이는 편이 낫습니다.
